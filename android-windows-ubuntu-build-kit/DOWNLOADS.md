## Hangi araç ne için?

- JDK 17: Android Gradle/Flutter Android derlemesi.
- Android command-line tools + sdkmanager: platform, build-tools ve emulator paketleri.
- platform-tools: adb/fastboot ve cihaz bağlantısı.
- Flutter: tek projeden APK/AAB ve Windows masaüstü uygulaması.
- Visual Studio Build Tools + Windows SDK: Windows native runner derlemesi.
- Git: kaynak kodu ve GitHub erişimi.
- Node.js: yardımcı scriptler ve web tabanlı araçlar.
- Rust/MSVC: Tauri gibi alternatif Windows paketleme seçenekleri.
